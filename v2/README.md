# Sanchi Ahuja portfolio

A static site: no build step. Open `index.html` to view it.

- `assets/data.js` holds all the content (feed posts, story milestones, projects, certifications, off the clock).
- `assets/site.css` holds the look. The five colours at the top re-theme the whole site.
- `assets/app.js` draws the pages from the content.
- `case-*.html` are the long case studies.
- `images/` and `media/` hold the photos and the Tuborg film.
